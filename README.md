# Спектр

Веб-приложение программы лояльности ЦП «Спектр». Node.js 24+ обслуживает интерфейс и API с одного адреса. Данные хранятся в SQLite. Зависимости устанавливать не нужно.

## Локальный просмотр

Запустите из папки проекта в PowerShell.

```powershell
$env:SPEKTR_DEMO = '1'
node server.js
```

Откройте [локальный «Спектр»](http://127.0.0.1:3000). В окне «Войти» доступны демо-аккаунты участника, специалиста, модератора и владельца. Для параллельного просмотра используйте разные профили браузера или обычное и приватное окно. Демо работает с отдельным файлом `data/demo.sqlite`.

При прямом открытии `index.html` браузер показывает оформленную стартовую страницу со ссылкой на локальное демо. Для работы с аккаунтами и данными нужен запущенный сервер.

`node --test` запускает проверки с временной базой.

## Размещение

Для общей работы нужен хост, который запускает Node.js, выдаёт HTTPS и сохраняет базу между перезапусками. Разместите приложение в корне домена. GitHub Pages обслуживает статические файлы и не запускает API.

| Переменная | Назначение |
| --- | --- |
| `SPEKTR_DB` | Путь к файлу SQLite на постоянном диске. По умолчанию `data/spektr.sqlite`. |
| `SPEKTR_OWNER_EMAIL` | Адрес владельца при первом запуске. |
| `SPEKTR_OWNER_PASSWORD` | Начальный пароль владельца из хранилища секретов хоста, минимум 12 символов. |
| `SPEKTR_HOST`, `PORT` | Адрес и порт прослушивания. По умолчанию `127.0.0.1:3000`. |
| `SPEKTR_HTTPS=1` | Включает Secure для cookie за HTTPS-прокси. |

Рабочая база рассчитана на запуск одного экземпляра приложения. Команда запуска — `node server.js`. Доступность процесса проверяется через `/api/health`. В рабочем окружении оставьте деморежим выключенным. После создания владельца стартовые переменные с его данными можно убрать.

При новой регистрации назначается роль участника. Владелец выдаёт роли специалиста и модератора и рассматривает заявки в модераторы. Специалисты отправляют события на модерацию, начисляют баллы и назначают штрафы. Модераторы публикуют события, задания, новости и награды.

## Настройки программы

Пороги рангов с незаполненными значениями задаёт владелец. Цены наград и начисления за задания задаёт команда при публикации. Сезонный сброс происходит 31 августа по Новосибирску. Правило угасания реализовано с шагом 30 дней, обнулением на 240-й день и округлением списаний до целых коинов.

Общая командная механика, нематериальные награды и перечень заданий требуют наполнения по итогам обсуждения команды. Предпочтение рассылки хранится в профиле. Для доставки писем требуется подключить почтовый сервис. Старые данные из браузера можно перенести после получения выгрузок и сверки записей с командой.
